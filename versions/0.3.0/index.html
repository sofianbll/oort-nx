Arcane devient Oort NX

Un nom, un thème et un numéro de version à lui. La base reste Arcane 0.2.1, par Bium23.

Nouveau

  • Le thème Oort

    Sombre par défaut si aucun thème n’était choisi, avec deux icônes : Trame ou Particules.

  • L’écran des jeux

    Choisis l’écran où s’ouvrent tes jeux, pour tous ou pour un seul.

Mieux

  • Transferts coupés

    Le motif et « Reprendre » restent visibles après l’alerte.

  • Disque plein

    Le volume concerné est nommé et la copie d’origine gardée.

  • Bibliothèque de référence

    Une confirmation avant de remplacer une app installée.

Réparé

  • Une raison, une fois

    Le panneau cloud ne répète plus un échec déjà affiché.

À savoir

Recompile Pokémon Légendes : Z-A pour que la touche + aille directement au jeu. Le choix de l’écran demande aussi un jeu compilé avec un moteur compatible.
