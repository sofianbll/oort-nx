Troubleshooting

Android0.1.0-alpha.14 steps3 min

  1. 1

    A game does not show

    Oort only sees apps whose package starts with org.nx2a.. Settings › Look again, then check Which games Oort finds.

    Checked with invented games : Where this comes from
    • android/tools/emulator_check.py
    • android/app/src/main/kotlin/io/github/sofianbll/oortnx/core/GameScanner.kt
  2. 2

    A game does not start

    Start it from Android’s home screen. If it fails there too, the problem is in the game.

    Read in the code, not tried : Where this comes from
    • android/app/src/main/res/values/strings.xml
    • android/app/src/main/kotlin/io/github/sofianbll/oortnx/core/GameLauncher.kt
  3. 3

    The controller answers badly

    Open Controllers › Try the buttons. If A and B are swapped, turn on Swap A and B.

    Checked with invented games : Where this comes from
    • android/tools/emulator_check.py
  4. 4

    Tell us

    Open a report with your device, your Android version and Oort’s. No game, key or save.

    • SECURITY.md
