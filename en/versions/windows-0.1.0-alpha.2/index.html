0.1.0-alpha.2

November 25, 2026WindowsLinux5 changes

Steam, icons and a welcome

The first player’s remarks: a guided start, Steam games, and programs with their real icon.

New

  • Icon and details

    A program you add gets its icon, name, publisher and version, read in its own file. So do the ones from alpha.1.

  • Steam games

    Installed games, on every drive, with their pictures. Steam starts them, Oort counts the time.

  • Guided setup

    Five short steps, with a controller or a keyboard, to skip or take up later.

  • Information online, if you say yes

    Cover, description, year, genres. Off until you choose.

Better

  • The empty screen and the + tile

    Clearer than before.

Good to know

Run the new installer over the old one: your library, play time and settings stay.

No game, key or emulator is included. No data is collected, no account.

Wikipedia limits anonymous requests: in practice, the Steam store answers most of the time.

Not there yet: Steam achievements, other stores, automatic updates, mods, the Home button in a game.

Not tried yet

Tried on fresh GitHub machines, with invented games, an invented Steam and invented services, the update from alpha.1 included. Not tried: the real Steam, the real online services, a real controller, Windows 10, a real graphics card, a Windows Steam game run by Proton.

Install

Windows: the installer is not signed. Compare the checksum, then “More info” and “Run anyway”. It installs for your account, without administrator rights.

Linux: .deb package for Ubuntu 24.04, Debian 12 and similar.
