0.1.0-alpha.3

November 26, 2026WindowsLinux8 changes

The same controls as on Mac

Mouse, keyboard, controller and touch follow the same rules as on Mac.

New

  • Control center

    Home or holding + opens it. + opens game options, Y searches and holding Home opens Settings.

  • Your controller’s controls

    Settings › Controllers › Controls shows Xbox, PlayStation, Switch Pro and Joy-Con layouts. Hints follow your last input.

  • Your installed games

    The Installed tab shows what you can play now. Drop a program or folder on the window to add it.

Better

  • Mouse and touch

    Scroll or swipe to choose, right-click or long-press for options. The on-screen keyboard has capitals, accents and digits.

  • Add game

    It is the first card when the library is empty. Select A folder of games for your recompiled games.

  • Online information

    Wikipedia and Wikidata receive the project’s public URL, not your data. The Steam store does not receive that URL.

Fixed

  • Back after a game on Linux

    Oort returns to the foreground on GNOME. The Linux package is smaller.

  • Back and Settings

    Back works with the mouse, and the first click or tap counts. The selected Settings row matches the page on screen.

Good to know

Install over the old version: games, recompiled-game folders, play time and settings stay.

No games, keys or emulators included. No account or data collection.

On Linux with X11, Oort may return in a window after a full-screen game. Press F11 twice. Wayland keeps full screen.

Not tried yet

Installation and update from alpha.2 were tried on Windows and Linux, with invented games. Not yet tried: Windows 10, a Steam Deck, one real controller from each family, a real touch screen and the real online services.

Install

Windows: x64 for Windows 10 or 11, ARM64 for Windows 11 on ARM. Compare the checksum. The installer is unsigned; SmartScreen may warn.

Linux x64: .deb package for Ubuntu 24.04, Debian 12 and similar.
