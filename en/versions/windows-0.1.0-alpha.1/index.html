0.1.0-alpha.1

November 25, 2026WindowsLinux6 changes

Oort leaves the Mac

The first trial version for Windows and Linux: the games you already have, in one library made for a controller.

New

  • Your library

    Recompilations that come with a recomplauncher.json, and any program with its arguments.

  • Start and follow

    Play time, the end of a session, a crash explained and the way back to Oort.

  • With a controller

    Xbox, PlayStation and Nintendo, on-screen keyboard included. The controller’s name shows on the home screen.

  • The cloud and the 27 palettes

    The same colors as on the Mac, from 80 to 125%.

  • Two-level settings

    Tried at once, then kept or dropped.

  • The four voices

    The sounds Oort makes.

Good to know

No game, key or emulator is included, and Oort downloads none. No data is collected.

Not there yet: copying a game’s files into its folder, mods, key bindings, the Home button in a game, wallpapers, automatic updates.

Uninstalling leaves your library in place.

Not tried yet

Tried on fresh GitHub machines (Windows Server 2025 and Ubuntu 24.04), with invented games: install, library, settings, launch, coming back, uninstall. Not tried: a player’s PC, a real controller, a real game, Windows 10, a real graphics card, sound by ear.

Install

Windows: the installer is not signed. Compare the checksum, then “More info” and “Run anyway”. It installs for your account, without administrator rights.

Linux: .deb package for Ubuntu 24.04, Debian 12 and similar.
