Ajouter tes jeux Steam

Linux0.1.0-alpha.24 étapes2 min

Ce guide décrit la 0.1.0-alpha.2. La 0.1.0-alpha.3 est sortie depuis. Ce qui change

  1. 1

    Active Steam

    Dans l’accueil guidé, la tuile + ou Réglages › Intégrations › Steam. Oort lit les jeux installés, sur tous les disques, et n’écrit rien chez Steam.

    Vérifié avec des jeux inventés : D’où ça vient
    • desktop/ui/app.js
    • desktop/tests/linux/prove.sh
    • Sources/OortCompanion/SteamShelf.swift
  2. 2

    Retrouve-les

    Leurs images sont celles que Steam garde déjà sur ton ordinateur. Les outils et les bandes-son sont laissés de côté ; un jeu doit être entièrement téléchargé.

    Vérifié avec des jeux inventés : D’où ça vient
    • desktop/ui/app.js
    • desktop/tests/linux/prove.sh
  3. 3

    Joue

    Jouer demande le jeu à Steam, qui le lance. S’il le met d’abord à jour, Oort attend ; Annuler arrête l’attente.

    Vérifié avec des jeux inventés : D’où ça vient
    • desktop/ui/app.js
    • desktop/tests/linux/prove.sh
    • desktop/src-tauri/src/steam.rs
  4. 4

    Reviens

    Quitte le jeu : Oort revient et compte le temps. Vérifié avec un faux Steam, jamais avec le vrai, ni avec Proton.

    Vérifié avec des jeux inventés : D’où ça vient
    • desktop/ui/app.js
    • desktop/tests/linux/prove.sh
Ce qui a été essayé

Essayé sur une machine neuve de GitHub (Ubuntu 24.04), avec des jeux inventés et un faux Steam. Jamais sur l’ordinateur d’un joueur.
