# Security reports

Do not post keys, game files, credentials, private paths or unreviewed logs in
public issues.

Use [Security → Report a vulnerability](https://github.com/sofianbll/oort-nx/security/advisories/new).
If that option is unavailable, ask the maintainer for a private channel outside
the tracker. Do not describe the issue or attach files in a public thread.

Include the Oort NX version, macOS version, the affected operation, the impact
and minimal steps using synthetic data. Flag issues in the latest release or
current development branch. There is no guaranteed response or fix time.
If a credential is already exposed, do not paste it again. The maintainer
coordinates any disclosure and any upstream contact privately.

Oort NX imports a private copy of keys, runs an external engine and
runs without the App Sandbox. Only import and launch game apps and engine
checkouts you trust. Repository checks and diagnostic redaction reduce common
mistakes; they do not replace reviewing what you share.
