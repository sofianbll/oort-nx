# 2026-11-27 · Layout and names: where each folder went

The repository moved into its target tree and its Swift modules took their Oort names, without changing what players see. Every move is a `git mv`, one commit per folder, so `git log --follow` and `git merge` follow each file. Names and module folders are declared once, in [`architecture/names.json`](../../architecture/names.json); its `former` entry keeps the layout below as data.

## Following from a branch started before

- Merge or rebase as usual: Git applies a change to a moved file at its new path.
- A file the branch added under an old folder: move it with `git mv` to the folder above.
- Swift: rewrite `import NXLibraryCore`, `import ArcanePorting`, `import NXLibrary` to `OortLibrary`, `NxnativeAdapter`, `OortMac`.
- Python: read paths and names from `scripts/names.py`; `scripts/check` refuses a name written by hand (`names`).
- An Arcane contribution (`bium/*`) maps its paths back with the folder table.
